# PROCESS-001 — Учёба как игра в различение

Идея подсмотрена у игры Эренфойхта—Фраиссе, но без попытки тащить сюда всю теорию моделей.

Есть две конкурирующие идеи, модели или реализации. Задача — придумать ход, который позволит различить их на практике.

Первым игровым полем будет сервер:

- разные параметры распределения;
- разные режимы нагрузки;
- разные оценки одного параметра;
- теория против Monte Carlo;
- статистическая модель против реальных данных;
- классический статистический метод против ML, если такое сравнение вообще имеет смысл.

Если сервера станет мало, подключается PostgreSQL, а затем реальные алгоритмы из других проектов.

Каждая глава Вассермана даёт новый игровой инструмент:

- среднее различает центры;
- дисперсия — разброс;
- bootstrap показывает нестабильность оценки;
- MLE ищет наиболее правдоподобный параметр;
- Фишер показывает разрешающую способность эксперимента;
- доверительный интервал очерчивает параметры, которые пока не удалось различить;
- Байес обновляет уверенность после нового хода.

Процесс одного раунда:

```text
поставил практический вопрос
→ выдвинул две версии
→ проверил, есть ли здесь осмысленный ML-конкурент
→ придумал различающий эксперимент
→ получил данные
→ попытался объяснить их обеими версиями
→ либо различил версии, либо понял, какой информации не хватает
```

Если ML-конкурент есть, сравниваются не названия и не количество `.fit()`, а предположения, качество результата, объём данных, объяснимость и вычислительная цена.

Если ML не даёт отдельного решения, это тоже результат: так и записывается, без натягивания нейросети или регрессии ради хайпа.

Женя не ведёт за руку к готовой формуле, а атакует слабые места версии и не даёт принять красивое совпадение за доказательство.

Цель игры — не победить и не пройти учебник. Цель — понять, какой инструмент что различает, какие предположения использует и когда перестаёт работать.

Теория получает жизнь через сервер, базу и алгоритмы. Практика перестаёт быть набором случайных замеров, потому что каждый эксперимент отвечает на заранее поставленный вопрос.

## 1. Концептуальное обоснование

При больших объёмах выборки ($n=10257$ запросов в логе `wrk`) используется непараметрический анализ. Теорема Гливенко—Кантелли гарантирует сходимость эмпирической функции распределения $\hat F_n(x)$ к истинной функции распределения.

Вместо вычисления параметров распределения внедряются статистические функционалы, которые через plug-in estimator возвращают точечные характеристики системы: среднее и квантили SLA.

## 2. Алгоритмические требования

Создать модуль `src/python/inference_core/nonparametric.py` и реализовать чистые функции без ООП-состояния.

### Эмпирическая CDF

- **Сигнатура:** `calculate_empirical_cdf(sample, x)`
- **Суть:** вычисляет $F(x)=P(X\le x)$ — долю запросов, завершившихся быстрее порога `x`.
- **Оптимизация:** использовать `bisect_right` для поиска за $O(\log N)$ в предварительно отсортированной выборке.

### Plug-in оценка квантиля

- **Сигнатура:** `calculate_plug_in_quantile(sample, p)`
- **Суть:** инвертирует эмпирическую CDF и возвращает физическую координату латентности для p95/p99.
- **Реализация:** извлечение значения из отсортированного массива по индексу, определяемому $p\cdot n$.

## 3. Полосы уверенности DKW

Для доверительного уровня $95\%$:

$$
\epsilon=\sqrt{\frac{\ln(40)}{2n}}.
$$

Для $n=10257$ ожидаемый радиус составляет примерно $1.34\%$.

## Comment: финальный технический аудит

Источник: https://github.com/kshakirov/Agnostic-Inference-Engine/issues/2#issuecomment-5200440569

`calculate_plug_in_quantile` должен возвращать поле метрики, а не весь POD-кортеж:

```python
return sample[ceil(q_value * len(sample))][1]
```

Текущий линейный расчёт CDF пригоден для проверки логики. Переход к `bisect_right` планируется после стабилизации контракта функции.

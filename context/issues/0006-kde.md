# Issue #6: KDE: плотность без заранее выбранной формы

- **State:** Open
- **Created:** 2026-10-12
- **Source:** https://github.com/kshakirov/Agnostic-Inference-Engine/issues/6

## Зачем

Четыре параметрические версии форму latency не вытянули. Вместо коллекционирования новых распределений иду к KDE: строю плотность прямо из данных, но без magic `.fit()`.

## Что уже пощупал

На ручной выборке `[1, 2, 2, 3, 7]` собрал Gaussian-ядро, вклад отдельной точки и полную оценку

```text
f(x) = сумма ядер / (n h)
```

Проверил симметрию: равноудалённые точки дают одинаковый вклад. Для `x=2`, `h=1` получилось `0.256365`. Затем сделал первый leave-one-out шаг: удалил `x=1` и оценил плотность в этой же точке по оставшимся данным — `0.134483`.

## Следующий ход

1. Пройти leave-one-out по всей ручной выборке.
2. Понять и собрать критерий выбора ширины `h`.
3. Только после этого применить прибор к реальным latency B/C.

Python пока Ground Truth. После понимания механику вынесу в чистый модуль.

# Issue #5: Real Server Latency: From Empirical Baseline to Parametric Model

- **State:** Open
- **Created:** 2026-08-31
- **Updated:** 2026-08-31
- **Source:** https://github.com/kshakirov/Agnostic-Inference-Engine/issues/5

## Зачем

Перестать крутить только синтетику и пройти всю машину вывода на живом сервере:

```text
сырой ответ сервера
-> эмпирика
-> гипотеза о распределении
-> MLE
-> оценка неопределённости
-> проверка модели на новых данных
```

Объект, данные, модель и оценки параметров не смешиваются. Normal — кандидат, а не заранее назначенная истина.

## Первый стенд

- локальный Haskell proxy;
- `GET http://127.0.0.1:9000/`;
- нагрузка через Vegeta;
- timestamp, HTTP status и latency сохраняются для каждого запроса;
- нагрузка сервера управляется частотой запросов и объёмом печати в консоль.

## Что должно получиться

- воспроизводимый протокол измерения;
- сохранённые сырые данные;
- эмпирические характеристики latency;
- явная параметрическая гипотеза;
- оценки параметров и их неопределённости;
- условия, при которых модель проигрывает;
- проверка на новой серии данных.

## Связь

Issue #4 остаётся синтетическим стендом и Ground Truth для MLE. Этот тикет — применение той же машины к объекту, настоящие параметры которого неизвестны.

## Comment: первый реальный checkpoint

Источник: https://github.com/kshakirov/Agnostic-Inference-Engine/issues/5#issuecomment-5474279194

Снята базовая серия:

```text
target:       GET http://127.0.0.1:9000/
Vegeta:       12.13.0
warm-up:      10 req/s, 10 s
measurement:  10 req/s, 60 s
observations: 600
HTTP errors:  0
```

Сохранены исходный `.gob` и полное CSV-представление Vegeta. В ad hoc-проходе взята третья колонка `latency_ns`, переведена в миллисекунды и посчитаны эмпирические оценки с `ddof=0`:

```text
mean     = 0.7333737967 ms
variance = 0.2483922664 ms^2
std      = 0.4983896732 ms
```

Среднее совпало со сводкой самой Vegeta.

Неутешительный итог дня: старые средства не оказались готовой универсальной библиотекой. Они завязаны на прежний кортеж `(status, latency)`, а `calculate_empirical_moments` под общим названием считает Bernoulli-статистику статуса, не моменты latency. Реальный источник сразу вскрыл ложную универсальность контракта.

Сейчас ничего архитектурно не ремонтируется. Следующий ход:

1. понять физический смысл полученных mean, variance и std и чего они не показывают;
2. решить, какие ещё эмпирические характеристики действительно нужны;
3. только затем выставить Normal-гипотезу;
4. получить MLE и оценку неопределённости через Фишера;
5. попытаться сломать модель на данных и новой серии.
